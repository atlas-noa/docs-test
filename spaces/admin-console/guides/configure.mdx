## Tenant Settings

1. Open the Admin Console.
2. Go to **Settings → General**.
3. Set your organization name, logo, and primary domain.

## Authentication

Configure how users sign in:

- **SSO Providers** — connect Okta, Azure AD, or Google Workspace
- **MFA Policy** — require MFA for admins, end users, or both
- **Session Timeout** — set idle and absolute session limits

## Roles and Permissions

Define who can do what:

| Role | Permissions |
| --- | --- |
| Owner | Full access |
| Admin | Manage users and apps |
| Auditor | Read-only access to logs |

## Save and Apply

Click **Save** at the bottom of each section. Changes take effect immediately.
