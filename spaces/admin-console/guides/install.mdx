## Prerequisites

- A Newcore tenant
- Administrator credentials
- Network access to `*.newcore.example.com`

## Install Steps

1. Sign in to your Newcore tenant.
2. Navigate to **Settings → Admin Console**.
3. Click **Install** and accept the permissions prompt.
4. Wait for the installation to complete (typically under a minute).

## Verify

After install, the Admin Console icon should appear in your top navigation bar.

## Troubleshooting

If the install fails, check the [Configure](./configure) guide for tenant requirements.
